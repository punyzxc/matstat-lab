# Scientist portraits (owner's ASCII art)

One plain-text file per scientist: `<slug>.txt`, slugs from `../../lectures/scientists.json`.
An empty file shows a labelled placeholder (name, years, one-line contribution).

Slot size: **40 columns × 20 lines** at full size, UTF-8, monospace characters only (a tab counts as 4 spaces).
Larger art is not clipped or wrapped: the whole picture is scaled down to fit the slot, so keep it near 40 × 20
for the crispest result. Paste the art into the file; nothing else to change. On the scene it types itself in
with a short sweep (shown at once for visitors who prefer reduced motion).
