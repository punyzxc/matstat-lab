## Proposed lesson sequence

**Assumption.** Each step has one main question/idea, a typeset formula or formula family, and optionally a worked example and station link. For a class, first ask for a prediction, change one parameter, observe the result, then ask which part is a single seeded observation and which part is a repeated-sampling/theoretical property. Do not interpret a fixed seed as evidence that every run satisfies a deterministic error bound. Extra proof algebra is optional board work; it is individually listed below rather than silently removed.

| Lecture | Proposed outcome and useful prerequisites | Script | Core route through the material |
|---|---|---|---|
| L4 | Distinguish a sampling rule from an unqualified geometric probability; prerequisites: events and length/area. | [L04.json](../../spikes/lecture-walkthroughs-random-variables/scripts/L04.json) | Measure → sin-squared example → Bertrand schemes → sigma-algebra/axioms → measurable pushforward. |
| L5 | Read atom masses, CDF and PDF without mixing endpoints or dimensions; prerequisites: L4 and elementary integration. | [L05.json](../../spikes/lecture-walkthroughs-random-variables/scripts/L05.json) | Definition → strict/inclusive CDF and indicator → density → Binomial, Poisson, Uniform, Normal, Exponential. |
| L6 | Distinguish center/spread, transformed laws and joint dependence; prerequisites: L5, sums/integrals. | [L06.json](../../spikes/lecture-walkthroughs-random-variables/scripts/L06.json) | This 43-page source is split into blocks: moments; normal tails; transformations; joint/conditional laws; convolution; covariance/regression. Teach in more than one class rather than racing through 33 steps. |
| L7 | Distinguish universal bounds from actual tails and a path from a convergence statement; prerequisites: expectation, variance, independence. | [L07.json](../../spikes/lecture-walkthroughs-random-variables/scripts/L07.json) | Markov → Chebyshev/tails → Chebyshev LLN → Khinchin/Cauchy → Bernoulli, varying probabilities, Markov variance condition. |
| L8 | Standardize a sum and state the assumptions of a normal limit; prerequisites: L6–L7 and normal CDF. | [L08.json](../../spikes/lecture-walkthroughs-random-variables/scripts/L08.json) | Distributional convergence → iid CLT → Lyapunov → Bernoulli/Uniform → Poisson endpoint example → limits of finite-n approximation. |
| L9 | Use characteristic functions and distinguish exact Binomial probabilities from approximations; prerequisites: L8 and complex exponentials. | [L09.json](../../spikes/lecture-walkthroughs-random-variables/scripts/L09.json) | CLT recap → characteristic functions/Phi conventions → five Chebyshev design examples → three binomial interval examples. |

**Assumption — activities.** L4: predict whether all ways of choosing a chord give the same answer, then compare the three schemes. L5: move only the CDF bound `x` across an atom. L6: move only `x4` on the beam, change only `alpha` for a transform, or change only `rho` in the normal cloud. L7: hold `k=3` fixed and change only the law to compare the bound and actual tail. L8: hold the source and seed fixed and change only the number of summands `n`; the histogram uses independent replicate streams and need not get closer at every successive n. L9: keep the event fixed and compare exact, plain normal and continuity-corrected values. Every script ends with 2–3 original Russian check questions and explicit answers; the questions test these distinctions rather than whether a button was clicked.

## Corrections visible to the teacher

**Fact — arithmetic and source readings.** These are teaching corrections with source pages, not edits to other owners' modules. All exact numeric worked-example values below are in the existing audit fixtures and are independently rechecked by [check_math.py](../../spikes/lecture-walkthroughs-random-variables/check_math.py). | Source | Printed version / ambiguity | Correct teaching statement |
|---|---|---|
| L4 p3 | The largest Bertrand probability is called the unique right answer. | Define the sampling rule: 1/2, 1/3, 1/4 describe different experiments. |
| L4 p4 | Sigma-algebra closed under any number of operations. | Countable unions/intersections are guaranteed; arbitrary uncountable closure does not follow. |
| L5 pp2–3 | Strict `P(X<x)` CDF; jumps are left-continuous. | This is a valid convention. The station uses `P(X≤x)`; subtract the jump to recover the lecture's strict value. For an indicator, show both endpoints explicitly. |
| L5 pp4–6,10 | A continuous range is treated as implying a density; a differential is read as a finite probability; failure CDF is called reliability. | State absolute continuity, derivative almost everywhere, exact finite-interval integral, and survival `S=1−F`. |
| L6 pp5,12 | Discrete median described as midrange; final normal fourth moment loses scale. | Median satisfies the two half-probability inequalities; normal fourth central moment is `3 sigma^4`. |
| L6 pp13–14 | `1−0.00135=0.9973`; outside percentages and four-sigma row wrong. | Both tails total 0.002699796063; central probability 0.997300203937. Four-sigma central probability 0.999936657516. All four corrected central/tail rows are in `L06-three-sigma`. |
| L6 p15 | Square probabilities reversed; `X²` said to differ from `X·X`. | Square masses are 1/3 at 0 and 2/3 at 1. The 2/9,5/9,2/9 product law requires two independent copies. |
| L6 pp17–18 | Affine formula can be read with no absolute value or at alpha=0. | Use `1/abs(alpha)` for alpha≠0; alpha=0 is a point mass. Increasing/decreasing CDF branches are qualified by continuity. |
| L6 pp24–25 | Intermediate matrix sums to 2. | Use the valid p24 joint table; all four products of row/column marginals factorize. |
| L6 pp31–33 | Two wrong middle cubic branches for four uniforms; sum CDF zero above support. | Correct density gives 23/48 at both 1.5 and 2.5. Two-uniform CDF is 1 above 2; Table5 values 1/8,1/2,7/8 remain correct. |
| L6 pp36–37 | Lottery variance called 1 for every n; prepare two prizes from mean plus standard deviation. | Mean is 1; variance is 1 for n≥2, zero at n=1. Mean plus SD is not a sufficiency guarantee. |
| L6 pp37–43 | Constant disc marginal; covariance/correlation matrix wording mixed; regression directions ambiguous. | Disc marginal is `2 sqrt(R²−x²)/(pi R²)`; distinguish covariance diagonal from correlation diagonal. Regression direction is named by what is predicted; best linear prediction need not be a true nonlinear conditional mean. |
| L7 p3 | Normal two-sided tail printed 0.00135; older map misreads Poisson sign. | Normal tail is 0.002699796063. Original Poisson bound already says ≤1/9; 0.018988156876 is a separate lambda=1 illustration, not every Poisson tail. |
| L7 pp4–6 | Finite variance stated as if needed for Khinchin; indicator variance written strictly below 1/4. | iid finite absolute mean suffices; Cauchy has no mean. Indicator variance is ≤1/4, with equality at p=1/2. |
| L8 pp1–3 | Equal means/variances stand in for iid; signed third moment in Lyapunov; convergence called in probability; unstandardized Uniform density compared to standard normal. | State the iid assumption for Lindeberg–Lévy, absolute third moments for Lyapunov, convergence in distribution, and `(sum−n/2)/sqrt(n/12)`. | L8 pp3–5 | Poisson additivity without an independence qualifier; strict and inclusive endpoints interchanged. | Require independent terms. At n=10 the strict probability is 0.457929714472, inclusive 0.583039750193; both tend to 1/2. The current station displays the inclusive sum. |

| L9 pp2–3,7–8 | Phi denotes three different functions; finite-n approximation written as equality. | Use `Phi_CDF`, `Phi0`, `erf`; their arguments differ by sqrt(2). Keep exact binomial and both normal approximations separate. |
| L9 pp3–7 | Five Chebyshev design examples. | Lower bounds 0.79,0.99,0.96 and sufficient sample 1225 are valid; strict >0.9 length requirement gives integer 16001, not 16000. These bounds are not exact probabilities or exact-law minimum sample sizes. |
