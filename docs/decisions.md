# Decisions

Every disagreement the team resolved, so nobody reopens it later (people and agents alike). Newest first. One entry per decision:

```
## YYYY-MM-DD — what was decided
- Chosen: …
- Alternatives: … (and why not)
- Why: … (link the research doc or the PR discussion)
- Decided by: @login (a person) / agreed by the areas …
```

The PRD links the decisions it relies on. Changing a decision is a new entry that says which one it replaces.
